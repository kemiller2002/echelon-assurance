# Known risks to this program

| Risk | Mitigation |
|---|---|
| Repository is public while containing assurance design | Owner to set private; content restricted to non-sensitive design |
| Research relies on public summaries of paywalled standards (ISO, some AICPA guides) | Evidence class capped; open questions for purchase decisions |
| Agent-generated research may contain citation errors | Source register with URLs and retrieval dates; source-accuracy review pass |
| Regulatory applicability depends on Unbound's undetermined legal/operating structure | Applicability `undetermined` + open questions to counsel |
| Over-engineering: building a compliance platform instead of using existing systems | Reuse-before-build rule; decision records for any new system |
